### 01 — selected work

six of these. all of them ship. none of them needed a design sprint to get there.

<br>

**[LockedIn](https://github.com/DevMahlatsi)** — `Next.js · Django · Celery · Redis · OpenAI`
AI-powered recruitment platform. Reads a CV, scores it against the job requirements, hands the
recruiter a ranked shortlist instead of 200 unsorted PDFs. Four role-based consoles, 25+ API
endpoints, async pipeline so nothing blocks on the AI call. Status: ongoing, because it's being
built right, not fast.

**[L-Tido Network](https://ltido-network.vercel.app)** — `React · YouTube Data API v3`
Full platform for two podcasts under one brand. Live YouTube stats, a 3-tier sponsorship page,
merch preview. 225K+ subscribers, 79+ episodes — pulled live from the API, not hardcoded like
most of these sites are.

**Open Chats Podcast** — `React · YouTube Data API v3`
A content hub and an investor pitch deck that happens to be a website. Built in two weeks for a
channel already pulling 606K subscribers and 70M+ views. The scope was small. The execution
wasn't rushed.

**AgriSmart** — `React Native · Django · Gemini AI · PostgreSQL`
Connects farmers directly to consumers. AI plant disease detection at 85%+ accuracy, an
interactive farm map, real-time weather data, three user roles. Led a 9-person team and wrote
most of the backend myself, because that was the part that had to not break.

**[Kokoro Stream](https://kokoro-stream.vercel.app)** — `React · Tailwind CSS`
Browse and search movies and shows without the fifteen layers of clutter most streaming UIs
ship with. Fast, clean, nothing decorative that isn't also functional.

**[Merch Bay](https://merchbay.vercel.app)** — `Next.js · Tailwind CSS`
A real storefront, selling real posters, on an actual campus. Not a portfolio piece dressed up
as a product — an actual product, with actual customers, that actually had to work.
